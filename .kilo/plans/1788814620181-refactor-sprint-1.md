# Refactoring Sprint 1 — Small, Low-Risk Fixes

## Overview

This sprint addresses the highest-priority, lowest-risk refactoring opportunities identified in the codebase analysis. All changes are behavior-preserving and touch 10 files.

## Tasks

### Task 1: Extract `calculateFleetStrength` to `ShipService`

**Why:** The exact same 6-line formula is copy-pasted into four AI services. Any change requires editing all four.

**Files to modify:**
- `src/app/services/ship.service.ts` — add `calculateFleetStrength(ships: { type: string }[]): number`
- `src/app/components/star-map/enemy-ai.service.ts` — remove private method, call `this.shipService.calculateFleetStrength(fleet.ships)`
- `src/app/components/star-map/enemy-strategy.service.ts` — same
- `src/app/components/star-map/enemy-goal.service.ts` — same
- `src/app/components/star-map/enemy-capability.service.ts` — same

**Implementation detail:** The new method on `ShipService` takes only the ships array, avoiding a circular dependency on the `Fleet` type.

---

### Task 2: Extract duplicated AI query helpers to `ai-queries.ts`

**Why:** `getEnemyFleets`, `getPlayerFleets`, `getEnemyPlanets`, `getUnhabitedPlanets` are identical private methods in `EnemyStrategyService` and `EnemyGoalService`.

**Files to modify:**
- Create `src/app/components/star-map/ai-queries.ts` with four exported functions:
  - `getEnemyFleets(factionId: string, fleets: Fleet[]): Fleet[]`
  - `getPlayerFleets(fleets: Fleet[], factions: Faction[]): Fleet[]`
  - `getEnemyPlanets(factionId: string, starSystems: StarSystem[]): StarSystem[]`
  - `getUnhabitedPlanets(starSystems: StarSystem[]): { system: StarSystem; planet: StarSystem['planetsTiles'][0] }[]`
- `enemy-strategy.service.ts` — remove private methods, import from `ai-queries.ts`
- `enemy-goal.service.ts` — same
