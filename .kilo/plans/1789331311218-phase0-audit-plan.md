# Phase 0 — Tactical Battle Result Persistence Fix

> Plan date: 2026-09-13
> Focus: Complete tactical battle result persistence (Goals 1+3)
> Scope: One coding task per prompt; implementation-ready

---

## Problem Statement

When a tactical battle ends and the player returns to the star map, the strategic game state does not fully reflect the battle outcome. Specifically, the winning fleet's position is not updated and its movement targets are not cleared, which can cause rendering issues and retrigger the same encounter.

## Current Behavior

The battle persistence pipeline works but has two gaps in `StarMap.applyBattleResult()` (`src/app/components/star-map/star-map.ts`, L2368-2388):

1. **Fleet position not snapped**: The winner fleet remains at floating-point coordinates from its last movement tick. Per `docs/invariants.md` Fleet Position Invariants (L20): "fleet.gridCol/gridRow must always equal Math.floor(fleet.x) and Math.floor(fleet.y)". This invariant is violated after battle.

2. **Movement targets not cleared**: The winner's `targetX`/`targetY` are not cleared. If the loser is at the same cell (before being destroyed), the battle detection service could retrigger the encounter. The `triggeredBattles` set is re-created on each `StarMap` instance (per invariants.md L53), so it won't actually retrigger, but leaving stale targets is incorrect.

Both gaps are in the same code path: `applyBattleResult()` is called from `removeDestroyedFleetFromService()` which is called from `reloadAfterBattle()` which is triggered when returning from `/battle` to `/star-map`.

## Design Decisions

1. **Winner stays at battle location** — The fleet that won the battle remains at the grid cell where the battle occurred, snapped to integer coordinates.
2. **Destroyed fleet is removed** — The loser is marked `destroyed = true` and filtered from all rendering/movement/economy code. Its position is irrelevant.
3. **Battle is self-contained** — The tactical minigame never mutates galaxy state directly. All writeback goes through `BattleService` transport → `StarMap` application layer.
4. **Per-ship HP and destroyed state** — Already correctly persisted via `BattleOutcome.attacker.ships[]` and `BattleOutcome.defender.ships[]` containing `hp` and `destroyed` per ship.
5. **No resurrection** — Destroyed ships stay destroyed because `persistFleetBattleResult()` and `applyBattleResult()` write final HP/destroyed to autosave, and `loadGame()` reads from autosave. `destroyedFleetId` ensures destroyed fleets stay destroyed across reloads.

### Implementation Change

In `StarMap.applyBattleResult()`, modify the fleet iteration to also snap positions and clear targets:

```typescript
private applyBattleResult(result: BattleOutcome): void {
  for (const fleetOutcome of [result.attacker, result.defender]) {
    if (fleetOutcome.fleetId < 0) {
      continue;  // Virtual planet-defense fleet — never persists
    }
    const fleet = this.fleets.find((f) => f.id === fleetOutcome.fleetId);
    if (!fleet) {
      continue;  // Guard: handle missing/invalid fleets safely
    }
    // Per-ship HP and destroyed state from battle outcome
    fleet.ships = fleetOutcome.ships.map((s) => ({
      id: s.shipId,
      name: s.name,
      type: s.typeId,
      currentHp: s.hp,
      destroyed: s.destroyed,
    }));
    // Fleet is destroyed only when it has no surviving ships
    if (fleetOutcome.wipedOut) {
      fleet.destroyed = true;
    }
    // Position fix: snap winner to grid cell, clear movement targets
    // so the fleet does not immediately retrigger the same encounter.
    if (!fleetOutcome.wipedOut) {
      fleet.x = Math.floor(fleet.x);
      fleet.y = Math.floor(fleet.y);
      fleet.targetX = null;
      fleet.targetY = null;
    }
  }
}
```

Key behaviors:
- **Surviving fleet**: Position snapped to integer grid coordinates via `Math.floor`. `targetX`/`targetY` cleared to `null`. Fleet not marked destroyed.
- **Destroyed fleet**: Marked `destroyed = true`. Position and targets NOT modified (fleet is filtered from all movement/rendering code when destroyed).
- **Empty fleets**: The `if (!fleet) continue` guard handles missing fleets. An empty fleet with `wipedOut = true` is still marked destroyed.
- **Planet battles**: The `fleetId < 0` check skips virtual defense fleets. Only the real attacker fleet's roster and position are updated. Planet ownership is handled separately by `backToStarMap()` → `applyPlanetBattleResult()`.

### Why This Is Safe

1. **Self-contained**: No changes to BattleScreen, battle services, or transport types. The `BattleOutcome` already carries all needed data (`hp`, `destroyed`, `wipedOut`, `fleetId`, `ships`).
2. **Position invariant restored**: After the fix, `Math.floor(fleet.x) === fleet.gridCol` holds (assuming `gridCol` was already correct from movement). The `movementService.refreshGridPositions()` call in `loadGame()` will re-derive `gridCol`/`gridRow` from the snapped position on next load.
3. **No retriggering**: Clearing `targetX`/`targetY` means the winner has no movement target. Battle detection checks `fleet.targetX !== null && fleet.targetY !== null` to determine the attacker (see `star-map-battle-detection.service.ts` L78-80). A fleet with no target cannot be the attacker, so it cannot retrigger.
4. **Loser position irrelevant**: The destroyed fleet is filtered from `visibleFleets`, `updateFleets()`, `checkForBattles()`, and `checkFleetPlanetArrivals()` per invariants.md L22-26.

#### Test 1: Fleet battle with surviving ships — position snapped and targets cleared

```typescript
describe('Battle return — fleet position update', () => {
  let saveGameService: SaveGameService;
  let battleService: BattleService;

  beforeEach(() => {
    saveGameService = TestBed.inject(SaveGameService);
    battleService = TestBed.inject(BattleService);
    saveGameService.currentSlot = SaveSlotId.AUTOSAVE;
    localStorage.clear();
  });

  it('snaps winner position to grid cell and clears movement targets', () => {
    component['saveGame']();

    const orion = component.fleets.find((f) => f.id === 1)!;
    const raider = component.fleets.find((f) => f.id === 2)!;
    orion.x = 18.7;
    orion.y = 42.3;
    orion.targetX = 25;
    orion.targetY = 40;
    raider.x = 18.5;
    raider.y = 42.1;

    const outcome: BattleOutcome = {
      winnerSide: 'attacker',
      winnerFleetId: 1,
      loserFleetId: 2,
      attacker: {
        fleetId: 1, side: 'attacker', factionId: orion.factionId,
        ships: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: s.currentHp ?? 100, destroyed: false,
        })),
        survivors: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: s.currentHp ?? 100, destroyed: false,
        })),
        wipedOut: false,
      },
      defender: {
        fleetId: 2, side: 'defender', factionId: raider.factionId,
        ships: raider.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: 0, destroyed: true,
        })),
        survivors: [],
        wipedOut: true,
      },
      rounds: 3,
      battleType: 'fleet',
    };
    battleService.setBattleResult(outcome);
    component['removeDestroyedFleetFromService']();

    const updatedOrion = component.fleets.find((f) => f.id === 1)!;
    const updatedRaider = component.fleets.find((f) => f.id === 2)!;

    // Position snapped to grid cell
    expect(updatedOrion.x).toBe(18);
    expect(updatedOrion.y).toBe(42);
    // Movement targets cleared
    expect(updatedOrion.targetX).toBeNull();
    expect(updatedOrion.targetY).toBeNull();
    // Fleet not destroyed (has survivors)
    expect(updatedOrion.destroyed).toBe(false);
    // Loser destroyed
    expect(updatedRaider.destroyed).toBe(true);
  });

  it('marks fleet destroyed when wiped out', () => {
    component['saveGame']();

    const orion = component.fleets.find((f) => f.id === 1)!;
    const outcome: BattleOutcome = {
      winnerSide: 'defender',
      winnerFleetId: 2,
      loserFleetId: 1,
      attacker: {
        fleetId: 1, side: 'attacker', factionId: orion.factionId,
        ships: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: 0, destroyed: true,
        })),
        survivors: [],
        wipedOut: true,
      },
      defender: {
        fleetId: 2, side: 'defender', factionId: 'enemy1',
        ships: [],
        survivors: [],
        wipedOut: false,
      },
      rounds: 1,
      battleType: 'fleet',
    };
    battleService.setBattleResult(outcome);
    component['removeDestroyedFleetFromService']();

    const updatedOrion = component.fleets.find((f) => f.id === 1)!;
    expect(updatedOrion.destroyed).toBe(true);
  });

  it('preserves damaged survivor HP after battle', () => {
    component['saveGame']();

    const orion = component.fleets.find((f) => f.id === 1)!;
    const originalShipId = orion.ships[0].id;

    const outcome: BattleOutcome = {
      winnerSide: 'attacker',
      winnerFleetId: 1,
      loserFleetId: 2,
      attacker: {
        fleetId: 1, side: 'attacker', factionId: orion.factionId,
        ships: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: 37, destroyed: false,
        })),
        survivors: [{ shipId: s.id, typeId: s.type, name: s.name, hp: 37, destroyed: false }],
        wipedOut: false,
      },
      defender: {
        fleetId: 2, side: 'defender', factionId: 'enemy1',
        ships: raider.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: 0, destroyed: true,
        })),
        survivors: [],
        wipedOut: true,
      },
      rounds: 2,
      battleType: 'fleet',
    };
    battleService.setBattleResult(outcome);
    component['removeDestroyedFleetFromService']();

    const updatedOrion = component.fleets.find((f) => f.id === 1)!;
    expect(updatedOrion.ships.find((s) => s.id === originalShipId)!.currentHp).toBe(37);
  });

  it('does not resurrect destroyed ships after save/load', () => {
    component['saveGame']();

    const raider = component.fleets.find((f) => f.id === 2)!;
    const outcome: BattleOutcome = {
      winnerSide: 'attacker',
      winnerFleetId: 1,
      loserFleetId: 2,
      attacker: {
        fleetId: 1, side: 'attacker', factionId: 'player',
        ships: component.fleets.find((f) => f.id === 1)!.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: s.currentHp ?? 100, destroyed: false,
        })),
        survivors: [{ shipId: s.id, typeId: s.type, name: s.name, hp: s.currentHp ?? 100, destroyed: false }],
        wipedOut: false,
      },
      defender: {
        fleetId: 2, side: 'defender', factionId: 'enemy1',
        ships: raider.ships.map((s) => ({ shipId: s.id, typeId: s.type, name: s.name, hp: 0, destroyed: true })),
        survivors: [],
        wipedOut: true,
      },
      rounds: 1,
      battleType: 'fleet',
    };
    battleService.setBattleResult(outcome);
    component['removeDestroyedFleetFromService']();
    component['saveGame']();
    component.loadGame();

    const updatedRaider = component.fleets.find((f) => f.id === 2)!;
    expect(updatedRaider.destroyed).toBe(true);
    expect(updatedRaider.ships.every((s) => s.destroyed)).toBe(true);
  });

  it('handles planet battle without modifying fleet position', () => {
    component['saveGame']();

    const sol = component.starSystems.find((s) => s.id === 'sol')!;
    const earth = sol.planetsTiles.find((p) => p.id === 1)!;
    const orion = component.fleets.find((f) => f.id === 1)!;
    orion.x = 18.7;
    orion.y = 42.3;
    orion.targetX = 25;
    orion.targetY = 40;

    const outcome: BattleOutcome = {
      winnerSide: 'attacker',
      winnerFleetId: 1,
      loserFleetId: -1, // virtual defender
      attacker: {
        fleetId: 1, side: 'attacker', factionId: orion.factionId,
        ships: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: s.currentHp ?? 100, destroyed: false,
        })),
        survivors: orion.ships.map((s) => ({
          shipId: s.id, typeId: s.type, name: s.name,
          hp: s.currentHp ?? 100, destroyed: false,
        })),
        wipedOut: false,
      },
      defender: {
        fleetId: -1, side: 'defender', factionId: 'enemy1',
        ships: [],
        survivors: [],
        wipedOut: true,
      },
      rounds: 2,
      battleType: 'planet',
      planetId: 1,
    };
    battleService.setBattleResult(outcome);
    component['removeDestroyedFleetFromService']();

    // Fleet position should still be snapped for planet battles too
    const updatedOrion = component.fleets.find((f) => f.id === 1)!;
    expect(updatedOrion.x).toBe(18);
    expect(updatedOrion.y).toBe(42);
    expect(updatedOrion.targetX).toBeNull();
    expect(updatedOrion.targetY).toBeNull();
    expect(earth.factionId).toBe('player');
  });

  it('handles empty fleets safely', () => {
    component['saveGame']();

    const outcome: BattleOutcome = {
      winnerSide: 'attacker',
      winnerFleetId: 99999, // nonexistent fleet
      loserFleetId: 99998,   // nonexistent fleet
      attacker: {
        fleetId: 99999, side: 'attacker', factionId: 'player',
        ships: [], survivors: [], wipedOut: false,
      },
      defender: {
        fleetId: 99998, side: 'defender', factionId: 'enemy1',
        ships: [], survivors: [], wipedOut: false,
      },
      rounds: 1,
      battleType: 'fleet',
    };
    // Should not throw
    battleService.setBattleResult(outcome);
    expect(() => component['removeDestroyedFleetFromService']()).not.toThrow();
  });
});
```
